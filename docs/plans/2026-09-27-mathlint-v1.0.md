# mathlint v1.0 "App stores" Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android and iOS apps built from the same web code, ready for Google Play and the App Store, and a stable Python package on PyPI.

**Architecture:** Capacitor 8 copies the built site (`_site`) into committed Android and iOS projects under `app/`. The page detects the app through `web/native.js` and behaves like one (no service worker, the back button, system bars). CI builds both apps and starts each in an emulator or simulator until the engine reports that it is ready; tagged releases sign and upload them when the maintainer has set the secrets up.

**Tech Stack:** Capacitor 8.5 (`@capacitor/core`, `android`, `ios`, `app`, `cli`), Gradle with JDK 21, Xcode with Swift Package Manager; the page's plain ES modules and `node --test`; Python 3.10+, pytest, ruff.

**Spec:** `docs/design/2026-09-27-app-stores-design.md`

## Global Constraints

- The page is not forked: the app runs the same `_site` the web serves; the only app-specific code is in `web/native.js`, and on the web it does nothing.
- Nothing is sent over the network; the only permission asked for is the camera.
- The app's version is `src/mathlint/_version.py`'s: `versionCode = major*10000 + minor*100 + patch`.
- `app/` is its own npm project with a lock file; the package's `uv.lock` is untouched.
- Every UI word, store listing and permission reason in en, ro, ru, es.
- Every commit: `uv run ruff check .`, `uv run pytest` and `node --test web/tests/*.test.mjs` pass. Commits are the maintainer's own.

### Task 1: The page inside an app

**Files:** Create `web/native.js`, `web/tests/native.test.mjs`; modify `web/app.js` (offline state, back button, theme → system bars, engine-ready log line), `web/style.css` (safe areas from Capacitor's variables, the coffee link hidden in the app), `web/locales/*.json` (`offline.app`), `scripts/build_web.py` (`native.js` in `_LOCAL_FILES`).

**Interfaces — Produces:**
- `nativePlatform(win = globalThis) -> "android" | "ios" | null`
- `hasPlugin(name, win) -> boolean`, `callPlugin(name, method, options, win) -> Promise`, `listen(name, event, callback, win) -> Promise`
- `backStep({ dialog, keypadOpen, tab }) -> "dialog" | "keypad" | "tab" | "leave"`
- `barStyle(theme) -> "DEFAULT" | "LIGHT" | "DARK"`

- [ ] Tests (node): no `Capacitor` → web, every call a no-op; a fake bridge on Android → calls reach `nativePromise`; back steps in order; bar style per theme.
- [ ] Tests (pytest): the service worker is not registered in the app; the coffee link is hidden in the app; the ready line is logged.
- [ ] Commit `feat(web): behave like an app inside the Android and iOS shells`.
