# mathlint v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship mathlint v0.1 — a mistake finder for worked math solutions (CLI, Python API, web page) — as a public GitHub release.

**Architecture:** Input text is normalised (unicode, LaTeX → plain), calculus notation is rewritten into SymPy `Derivative`/`Integral` calls, and each line is parsed with a sandboxed `parse_expr`. Checkers compare consecutive lines numerically first (to find counterexamples) and symbolically second (to prove equality), producing a `Report` rendered as text, Markdown or JSON.

**Tech Stack:** Python ≥ 3.10, SymPy ≥ 1.12, hatchling, pytest, ruff, uv; web page with Pyodide v314.0.7 + KaTeX from jsDelivr; GitHub Actions.

**Spec:** `docs/design/2026-09-17-mathlint-design.md`

## Global Constraints

- Python `>=3.10`; runtime dependency only `sympy>=1.12`.
- Package name `mathlint`; src layout `src/mathlint`; version `0.1.0` in `src/mathlint/_version.py`.
- Verdicts exactly: `OK`, `WRONG`, `WARNING`, `UNSURE`. `WRONG` always carries evidence.
- Max 2000 characters per line; `__builtins__` emptied for `parse_expr`; reject literal exponents > 10 000 and factorials > 1000.
- CLI exit codes: 0 no errors, 1 a `WRONG` step, 2 input/usage error. Honour `NO_COLOR`.
- `e` = Euler's number, `C` = plain symbol, `i` = plain symbol, `log` = natural log.
- Web page: no server; input only in URL hash.

### Task 2: Plain-text parser

**Files:** Create `src/mathlint/parse/__init__.py`, `parse/unicode.py`, `parse/plain.py`; Test `tests/parse/test_plain.py`

**Interfaces — Produces:**
- `normalize_unicode(text: str) -> str`
- `parse_expression(text: str) -> Parsed` where `Parsed(expr: sympy.Expr, warnings: list[str])`
- `SYMBOL_E = sympy.E` mapping, `read_as(expr) -> str` (SymPy string with `^`)

Test cases (input → expected SymPy):
- `2x sin x + x^2 cos x` → `2*x*sin(x) + x**2*cos(x)`
- `x(2sin(x) + x cos(x))` → `x*(2*sin(x) + x*cos(x))`
- `e^x` → `exp(x)`; `x e^x - e^x` → `x*exp(x) - exp(x)`
- `sin^2(x) + cos^2 x` → `sin(x)**2 + cos(x)**2`
- `sin^-1 x` → `asin(x)`; `ln|x|` → `log(Abs(x))`; `|x - 1|` → `Abs(x - 1)`
- `sin 2x` → `sin(2*x)`; `sin x cos x` → `sin(x)*cos(x)`; `sqrt x` → `sqrt(x)`
- `3 − 2·x²` (unicode) → `3 - 2*x**2`; `π` → `pi`
- `1/2x` → `x/2` **and** a warning containing `1/(2x)`
- `e^2x` → `x*exp(2)` **and** a warning containing `e^(2x)`
- Rejected with `ParseError`: `__import__('os')`, `x.real`, `9^9^9^9`, `100000!`, a 2001-char line, `sin` (no argument), `(x+1` (unbalanced)

- [ ] Write tests → run (fail) → implement → run (pass) → commit `feat(parse): safe plain-text expression parser`.

### Task 3: Calculus notation

**Files:** Create `src/mathlint/parse/calculus.py`; Test `tests/parse/test_calculus.py`

**Interfaces — Produces:** `rewrite_calculus(text: str) -> str` (called inside `parse_expression` before other rewrites).

Test cases (via `parse_expression`):
- `d/dx x^2 sin x` → `Derivative(x**2*sin(x), x)`
- `d/dx(x^2) + 1` → `Derivative(x**2, x) + 1`

- `int x e^x dx` → `Integral(x*exp(x), x)`
- `x e^x - int e^x dx` → `x*exp(x) - Integral(exp(x), x)`
- `int_0^1 x^2 dx` → `Integral(x**2, (x, 0, 1))`; `int_(0)^(pi/2) sin x dx` → `Integral(sin(x), (x, 0, pi/2))`
- `∫ 2t dt` → `Integral(2*t, t)`
- `int x^2` → `ParseError` mentioning `dx`

- [ ] Write tests → fail → implement → pass → commit `feat(parse): derivative and integral notation`.

### Task 5: Document parsing

**Files:** Create `src/mathlint/document.py`; Test `tests/test_document.py`

**Interfaces — Produces:**
- `Mode = Literal["chain", "equation"]`
- `Line(number: int, raw: str, kind: Literal["expression","equation","solutions"], expr: Expr | None, equation: tuple[Expr, Expr] | None, solutions: list[Expr] | None, no_solution: bool, arrow: Literal["", "=>", "<=>"], warnings: list[str])`
- `Document(mode: Mode, lines: list[Line], variable: Symbol | None)`
- `parse_document(text: str) -> Document` (raises `ParseError` with `.line` set)

Test cases:
- chain: `"(x+1)^2\n= x^2 + 2x + 1"` → mode chain, 2 lines, leading `=` stripped
- comments/blank lines skipped, original line numbers kept
- equation: `"x^2 - 5x + 6 = 0\n(x-2)(x-3) = 0\nx = 2 or x = 3"` → mode equation; line 3 kind `solutions` `[2, 3]`
- `solve 2x = 4` → equation; `=> x = ±2` → arrow `=>`, solutions `[2, -2]`; `\iff x = 1` → arrow `<=>`
- `x = 2, x = 3` → solutions; `no solution` → `no_solution=True`
- equation with two unknowns `x + y = 1` → `UnsupportedError`
- parse error on line 3 → `ParseError.line == 3`

- [ ] Write tests → fail → implement → pass → commit `feat: document parsing and mode detection`.

### Task 6: Equivalence engine

**Files:** Create `src/mathlint/numeric.py`, `src/mathlint/equivalence.py`, `src/mathlint/hints.py`; Test `tests/test_equivalence.py`, `tests/test_hints.py`

**Interfaces — Produces:**
- `Verdict(str, Enum)`: `OK`, `WRONG`, `WARNING`, `UNSURE`
- `Comparison(verdict: Verdict, method: str | None, message: str, counterexample: dict[str, str] | None, values: tuple[str, str] | None, hints: list[str])`
- `compare(a: Expr, b: Expr, up_to_constant_in: Symbol | None = None) -> Comparison`
- `sample_points(symbols: list[Symbol]) -> list[dict[Symbol, Rational]]`
- `find_hints(a: Expr, b: Expr) -> list[str]`

Test cases:
- `(x+1)**2` vs `x**2+2*x+1` → OK, method `exact`
- `x*(2*sin(x)+x*cos(x))` vs `x*(2*sin(x)-x*cos(x))` → WRONG, counterexample `{"x": "1"}`, hint mentions `x*cos(x)` and `sign`
- `sqrt(x**2)` vs `x` → WARNING mentioning `positive`
- `Integral(x*exp(x), x)` vs `x*exp(x) - exp(x) + C` with `up_to_constant_in=x` → OK
- `Integral(x*exp(x), x)` vs `x*exp(x) + exp(x)` with `up_to_constant_in=x` → WRONG
- `Derivative(x**2*sin(x), x)` vs `2*x*sin(x) + x**2*cos(x)` → OK
- `Integral(x**2, (x, 0, 1))` vs `Rational(1, 3)` → OK
- hints: `-(x+1)` vs `x+1` → "sign of the whole expression"; `2*x` vs `x` → "factor"; `x+3` vs `x+1` → "constant"; `x**2+x` vs `x**2` → "term x ... disappeared"
- `log(-x**2-1)` vs `0` (never real) → UNSURE

- [ ] Write tests → fail → implement → pass → commit `feat: numeric-first equivalence engine with hints`.

### Task 7: Chain checker, equation checker, Report, `check()` API

**Files:** Create `src/mathlint/check/__init__.py`, `check/chain.py`, `check/equation.py`, `src/mathlint/report.py`; Modify `src/mathlint/__init__.py`; Test `tests/test_check_chain.py`, `tests/test_check_equation.py`, `tests/test_report.py`

**Interfaces — Produces:**
- `Step(line: int, raw: str, read_as: str, verdict: Verdict | None, method: str | None, message: str, hints: list[str], counterexample: dict[str,str] | None, values: tuple[str,str] | None, warnings: list[str])` (line 1 has `verdict=None`)
- `Report(mode: str, steps: list[Step], notes: list[str])` with `.ok: bool`, `.first_error: Step | None`, `.to_text(color: bool = False) -> str`, `.to_markdown() -> str`, `.to_dict() -> dict`
- `mathlint.check(text: str) -> Report` (raises `ParseError`/`UnsupportedError`)

Test cases:
- README example (derivative, sign flip on line 4) → `first_error.line == 4`, `ok is False`
- correct integration by parts chain ending in `+ C` → `ok`, no warnings
- same without `+ C` → note/warning "add + C"
- chain whose last line still has `d/dx` → warning "not finished"
- equation: `x^2 = x` → `x = 1` → WRONG "lost x = 0"
- equation: `sqrt(x) = x - 2` → `x = (x-2)^2` (WARNING extra) → `x = 1 or x = 4` → WRONG "x = 1 does not satisfy line 1"
- equation all correct → ok
- `to_dict()` JSON-serialisable; `to_text()` contains `First error: line 3 -> 4`; `to_markdown()` has a table header

- [ ] Write tests → fail → implement → pass → commit `feat: chain and equation checkers with reports`.
