Type it as you would say it: 2x sin x + x^2 cos x, e^x, ln|x|, d/dx (x^2), int x e^x dx. LaTeX works too. Solving an equation? Put the equation on line 1 and end with x = 2 or x = 3.

Write it as [[2, 1], [3, 4]], MATLAB style [2 1; 3 4], or as a LaTeX pmatrix. Fractions stay exact — no decimals.
