# Name and branding

The public software license grants rights in mathlint's code. It does not grant
rights to use the mathlint name, logo or other project branding in a way that
suggests a modified version is official, sponsored or endorsed by happy2rave.

You may make truthful references to mathlint, describe compatibility, link to
the official project, and preserve attribution notices. Modified distributions
should clearly identify themselves as modified and should use distinct branding
unless the copyright holder gives written permission.
